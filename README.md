# 🏢 Active Directory Home Lab (`lab.local`)

A hands-on systems administration lab focused on deploying, managing, and securing a Windows Server Active Directory environment using both GUI tools and PowerShell.

---

## 📐 Lab Setup

* **Domain Controller (`DC-01`):** Windows Server 2022 | `192.168.50.10`
* **Client Workstation (`WIN10-PRO`):** Windows 10 Pro | `192.168.50.20`
* **Domain Name:** `lab.local`
